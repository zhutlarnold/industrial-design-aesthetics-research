# 证据与同类比较 / Evidence and comparison

先列产品身份、型号/配置、时间口径、原图与来源。设计年、生产年、网页年、特定藏品年不同；概念车、量产车和改款不同；设计师晚年回顾不能冒充最初委托记录。

## 资料如何支持分析

| 内容 | 所需依据 |
|---|---|
| 照片里哪条线、什么明暗、哪处空隙 | 实际看过的对应版本原图；以“图中可见”限定 |
| 功能、材料与结构事实 | 参与者或厂商档案、博物馆记录、可信技术文件；品牌宣传与实测分开 |
| 设计师明确意图 | 本人陈述或直接访谈，定位日期与段落；缺则说明 |
| 本文美学解读 | 图像观察与上述事实组成明确前提；不借作者口吻加强判断 |
| 审美偏好、性能、传播效果 | 对应调查或实验；不能相互替代 |

记录实际检索词、访问日期、来源URL、对应主张、定位与未确认字段。优先设计师/厂商档案、主办方数据、博物馆和基础美术教材。补齐具体问题缺口，不为了数量反复搜同一来源的转载。打不开就标明，不把搜索摘要写成全文已读。

## 比较何时有用

当多个产品用途可比、形态不同而且有资料与图像，选择通常3—5项并列看。同类不要求同价位或同品牌，但说明功能与对象范围；不能把这类编辑比较说成实验。用户指定单件则细读，不靠“没有同类”解释不比较。

比较使用共同维度，例如轮廓方向、实体与空隙、比例、明暗主次、重复、与整机关系。不同设计可突出不同关系，但不能一款只谈历史、一款只谈性能、一款只谈外观后宣布美学排名。摄影角度、曝光、背景不同需承认；不能从图量真实亮度、尺寸、使用效率。

可用对照表帮助读者看差别，正文仍展开“为什么”。末尾指出不同风格如何成立，不把主观偏好藏进技术权威。

## 对“最好看”的数据要求

记下调查对象、样本量、招募方式、候选范围、时间、题目/指标、有效票分母、权重、公开原始数据及利益关系。缺失项照实留空；公开数据不足时说明获得何种认可，不能证明普遍最好。

- 纯外形偏好：可证明所研究样本在该任务中的选择；仍受样本与题目约束。
- 综合行业奖：同时考虑技术、设计或使用体验，不自动是审美票。
- 技术奖、光学安全测试：证明相应技术指标，不证明美。
- 销量、关注度、单条爆款、品牌自述：不能直接证明外形喜欢率。

2023车灯案例有两个不同类别的“年度颜值车灯”，权重20/50/30，但缺原始票数；2025 DVN公布整体796票、122家公司，以及前灯26/23/16占比，缺前灯有效分母和单独审美指标。不能用796乘占比换成人数、算显著差异，或将两个类别拼成统一排行榜。数据仅用于可核对的选材依据，原始出处见案例全文。

样本不足不会阻止形式分析：改变命题，写“这些获认可的设计用了哪些不同方法”，或明确“以下是编辑选择”。无网络只分析给定资料；不捏造新调查。

Evidence supports a bounded claim. An award, a marketing release and its reposts are not independent surveys; source count is not evidence diversity.
